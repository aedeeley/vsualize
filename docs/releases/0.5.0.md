# Vsualize 0.5.0

Vsualize now provides automatic session limits, a true Stop control and optional settings for gentler visuals and lower rendering workload.

- **30-minute automatic stop by default**, including existing installations. Choose 15, 30, 60 or 120 minutes in Safety & performance. Unlimited requires acknowledgement and is remembered locally.
- **Stop replaces freeze-frame Pause.** It clears the visual to opaque black and stops rendering and audio capture while keeping the window in place. Resume starts a fresh session. Space and a native tray action are available.
- Hidden/minimized sessions suspend rendering and capture. The deadline still runs. Sleep, workstation lock and session expiry require explicit Resume.
- A static health notice appears before the first animated frame or capture after this upgrade. Choose Start visuals or Keep stopped; the guidance remains available from settings.
- **Gentler visuals** reduces intensity, glow and reaction without overwriting saved effect profiles. **Eco: Auto/30** lowers the requested frame rate. Existing artwork, saved quality choices and the Auto/60 default are preserved.
- Native capture deadlines and asynchronous start/stop guards prevent stale starts from reopening a stopped session. Profile imports cannot change safety acknowledgements or the Unlimited choice.
- Added dependency security checks, private vulnerability reporting and health/display-care documentation.

Flashing light and moving patterns may cause symptoms, including seizures. Stop if symptoms occur. Session limits, Gentler and Eco are preference/exposure controls, not medical or hardware guarantees; 30 minutes is a product precaution, not an established safe viewing duration. Stopping Vsualize does not turn off the monitor. See [safety guidance](https://github.com/aedeeley/vsualize/blob/v0.5.0/docs/guides/safety.md).

Validation: 269 JavaScript tests, 32 Rust tests, 13 browser safety scenarios and a live WebView2 remote-origin rejection check. Full flash conformance analysis and parts of supervised Windows lifecycle testing remain incomplete; preliminary screening did not establish a formal failure or pass. See the [verification record](https://github.com/aedeeley/vsualize/blob/v0.5.0/docs/reports/safety-verification.md).

Update through Settings → App → Check for updates, or download `Vsualize_0.5.0_x64-setup.exe`. The updater verifies the installer signature and signed version. The installer does not have a Windows Authenticode publisher certificate. This release contains the production build; diagnostic logging/test navigation are disabled.
