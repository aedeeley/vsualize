# 0.2.7: smooth progressive motion

## Scope

This update keeps the existing 26-effect library and addresses the motion problems
shown in the user's Ripple and Iridescent Julia recordings. It does not introduce
a six-band instrument classifier or a separate explosion pack. Low/mid/high
features, a 128-bin spectrum, and independently detected attacks remain the inputs.
No external artwork, video frames, or Kauna/VVavy source is included in the app.

## Two response lanes

`VisualInertia` applies an analytically integrated critically damped follower to
geometry energy and individual spectrum bins. Its target response changes with
the persisted `smoothness` setting (default 0.75). This avoids frame-dependent
lerping, abrupt spectrum-packet jumps and spring overshoot. Sustained frequency
energy still reaches its target; smoothing is not a permanent amplitude reduction.
Native meters and the onset detector remain live and unsmoothed by this new lane.

`MotionDriver` accumulates positive travel and evolving phases. Musical targets
change velocity, not absolute position. Rotation is secondary; color evolution is
slower. Music-only motion now coasts to rest over 1.6 seconds instead of stopping
at the earlier 0.8-second cutoff. Explicit ambient drift stays optional.

Fast low/mid/high attacks still birth particles and waves and accent local detail.
Twenty-four impulse slots have 4.8-second lifetimes with smooth fades; a full pool
skips an additional ring rather than teleporting an existing one to the center.
Whole-frame flash gain is reduced while local accents remain.

Ripple's workload scales from 32 to 72 contour rings with the selected quality
and uses the heavy-effect pixel budget. Its projected surface is an original
procedural interpretation, not a physical fluid solver or an exact Kauna port.

## Integration and build hygiene

The interface adds Motion smoothing and a Use smooth music response reset. Old
settings acquire the default without discarding favorite effects, palette, devices
or capture gain. The reset does not restart capture.

The TypeScript compiler is invoked as a Node script with `shell:false`, avoiding
the old Windows shell-plus-arguments deprecation warning. Native `WAVE` is imported
under `cfg(test)` because the native tests still use it. Native capture/window APIs
and dependency versions are unchanged. The outer 4px clipping is unchanged.

## Limits

Fractal flight uses finite floating-point precision and crossfaded inward legs,
not arbitrary-precision infinite zoom. Fine fractal boundaries may still shimmer
at low render resolution. Higher quality costs GPU time. Performance on the
user's hardware is not established by Mesa software-renderer checks.

The work is not installed on the user's computer. Build and run the updated
source, or build a new installer for a separately installed copy. Windows native
compilation, caption behavior, WebView2 compositing and live audio are not validated
here. See the versioned test report for the actual test scope.
