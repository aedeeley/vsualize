# Vsualize 0.4.0

The new visual controls and filmstrip menu are now available in the Windows app.

- Browse effects in a floating horizontal filmstrip and open each effect's controls with its cog.
- Tune rotation and pattern detail independently, with additional controls for Mandala, Kaleidoscope, Dissolution, Organism, Overdrive, and Lava.
- Explore richer illustrated Kaleidoscope patterns, updated Organism rendering, Soundform zoom, and refined music response.
- See the current song and artist while controls are open, when your Windows media player provides them.
- Open Settings → Audio for capture sources and device options, or Settings → App for appearance and updates.

Existing installations can use **Check for updates**, followed by **Install update and restart**. Downloads verify the installer signature and release version using the existing update key. Audio devices, saved settings, and the application identity remain compatible. Spin and pattern-detail settings are saved on each device separately from exported effect profiles.

For a new installation, download `Vsualize_0.4.0_x64-setup.exe`. The accompanying `.sig`, `latest.json`, and `SHA256SUMS.txt` files support verified updates and downloads.

The installer is update-signed but does not have a Windows Authenticode certificate. Windows may show an unknown-publisher or SmartScreen prompt.
