# Vsualize 0.3.1

This release brings the new ripple identity to the Windows app and repository. The toolbar now uses the new wordmark, and the installer, taskbar, shortcut, and system tray use matching icons. Browser previews and web entry points include the new favicon, app icons, and social artwork.

The visual effects, audio behavior, saved settings, application identity, and signed update channel remain compatible with 0.3.0.

Download `Vsualize_0.3.1_x64-setup.exe`. The `.sig`, `latest.json`, and `SHA256SUMS.txt` files support verified updates and downloads; users do not need to open them.

The installer is update-signed but does not have a Windows Authenticode certificate. Windows may show an unknown-publisher or SmartScreen prompt.
