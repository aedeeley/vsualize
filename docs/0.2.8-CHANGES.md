# 0.2.8: focused library

Remove exactly Orbital Vortex (`orbital`), Chromatic Vortex (`vortex`),
Pulse Tunnel (`pulse`), Chromatic Chaos (`chaos`) and Silk Weaver (`weaver`).
The collection decreases from 26 to 21. No new visualizers, features or re-tuning.

Their modules, registry entries, thumbnails and reference-search entries are
removed. Navigation, shuffle and favorites use the existing catalog allowlist.
The existing settings sanitizer selects Ripple Classic for a removed current ID
and drops only removed/invalid favorites. Valid selections and preferences remain.

Folder merges do not remove obsolete files. `scripts/prune-retired-visuals.mjs`
therefore removes only `src/visuals/{orbital,vortex,pulse,chaos,weaver}.ts` before
TypeScript compilation. It is idempotent, never recursively removes a directory,
and leaves dependencies, build caches, other effects and preferences alone.
This prevents old modules with retired IDs causing a compile failure on update.

The 21 retained effect modules, shared GLSL, renderer, motion/audio processing,
CSS/corners, native Rust code and Windows launchers match 0.2.7 byte-for-byte.
Version fields in package/Cargo/Tauri/UI/diagnostics become 0.2.8. No new dependencies.
The generated preview and documentation show the smaller library. Historical
version-specific test reports and change notes remain marked as historical.

Quit, merge the source contents, run UPDATE-WINDOWS.cmd and check 0.2.8.
No settings reset needed. For a separate installed app, rebuild/run the installer.

No Windows executable is included; Windows compilation and native operation
remain unverified in this environment. See TEST-REPORT-0.2.8.md for current tests.
