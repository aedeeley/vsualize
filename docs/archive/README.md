# Historical records

- `patches/`: notes from earlier visual and window updates.
- `reports/`: recorded validation reports for particular releases.
- `manifests/`: original source inventories and checksums.
- `data/`: earlier collection metadata and screenshot-derived defaults.
- `start-here-0.3.0.txt`: the former release-package entry note.

Manifest JSON and fixture hashes preserve their original paths and bytes. They describe the source packages they shipped with, before this repository was reorganized. Do not use them as a current file inventory or overwrite them to match a new layout.

For current commands, start with the [development guide](../guides/development.md). The old `SETUP-WINDOWS.cmd`, `START-WINDOWS.cmd`, `UPDATE-WINDOWS.cmd`, `REBUILD-WINDOWS.cmd`, and `BUILD-INSTALLER.cmd` references in historical notes are now covered by the root `vsualize.cmd` menu.
