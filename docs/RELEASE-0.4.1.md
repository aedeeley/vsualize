# Vsualize 0.4.1

Updates are easier to discover without leaving the visualizer.

- Vsualize checks for updates automatically at startup and every 12 hours while running.
- If Windows sleeps through a scheduled check, the app catches up when you return.
- When an update is available, a small dialog offers **Update and restart** or **Later**. Escape also dismisses it so you can continue using the app.
- **What’s new** opens that version's changelog in your default browser.
- The dialog shows download and installation progress, and lets you retry or dismiss if a download fails.
- A minimized app waits until restored to show the prompt. Failed background checks stay quiet.

Installation still requires your explicit choice and verifies the signed installer and version. Manual **Check for updates** remains available under **Settings → App**.

Update from your current app, or download `Vsualize_0.4.1_x64-setup.exe`. Existing settings are retained. The installer has an update signature but no Windows Authenticode publisher certificate.
